# Experimental status and discrepancy record

## Preservation rule
The package does not overwrite an observed experimental state merely to improve the appearance of results. `INSUFFICIENT` retrieval decisions and retrieval-attempt records remain part of the notebook evidence.

## Historical discrepancy
The project checklist supplied by the authors requires an explicit record of a **4/10 vs 10/10 retrieval discrepancy**. This discrepancy is documented here as a historical comparison and is **not converted into a fabricated accuracy percentage**.

## Important source distinction
The 19-page reference corpus contains a synthesized local-results table. The notebook contains the actual executable history available in the preserved notebook snapshot. These should not be conflated.

## Reconstructed result file
`results_from_reference_corpus_RECONSTRUCTED.csv` is a transparent reconstruction of the local-results table stated in the 19-page corpus. It is **not claimed to be the original historical CSV**.

## Missing original archive
The original ZIP archive was not available in the accessible Library at packaging time. This package is a rebuilt archive from the project files and evidence currently accessible. If the original ZIP is provided, its historical CSV can be inserted unchanged and the reconstructed file can be removed.
