# Experiments

The original notebook contains a ten-question evaluation scaffold comparing:

- LLM-only generation,
- standard RAG,
- Agentic RAG.

The ten questions cover RAG definitions, hallucination reduction, system components, Agentic RAG, retrieval, self-reflection, corrective retrieval, challenges and future directions.

## Evaluation fields

The original notebook creates fields for answers and timing, followed by a manual-evaluation table with correctness and evidence columns.

## Important distinction

The supplied draft paper explicitly says the experimental results, comparison tables, graphs, discussion and final conclusion were to be added after planned experiments. Therefore this package treats the evaluation as an executable experiment scaffold and does not manufacture final accuracy scores.
