# Agentic RAG Research Project — Complete Evidence Package

**Authors**
- Ms. Adithya Vinod

This archive packages the preserved Agentic RAG notebook/source, editable and PDF paper, 19-page research corpus, evaluation materials, experimental configuration, and 11 Colab/web-evidence screenshots.

## Research scope
The project studies Retrieval-Augmented Generation (RAG) and an Agentic RAG workflow with retrieval, evidence verification, adaptive re-retrieval, and refusal when evidence remains insufficient. The preserved notebook includes Qwen3-4B, FAISS, MiniLM/Sentence-Transformer-related experimentation, and agentic retrieval logic.

## Package structure
- `paper/` — editable paper, original draft snapshot, PDF paper
- `notebook/` — `.ipynb` notebook and original library JSON snapshot
- `corpus/` — 19-page Agentic RAG reference corpus
- `evidence/` — 11 supporting screenshots
- `evaluation/` — manual evaluation reconstruction, configuration, and transparent reconstructed results table
- `docs/` — experimental status/discrepancy documentation and checklist
- `metadata/` — citation metadata and file checksums

## Reproducibility note
API keys are not included. The notebook uses environment/Colab secret access rather than embedding credentials.

## Results integrity
No fabricated correctness percentage is introduced. The package explicitly distinguishes the executable notebook evidence from the synthesized results table contained in the 19-page corpus. The original historical CSV was not available in the accessible file library during this rebuild, so the included results CSV is explicitly labelled `RECONSTRUCTED`.
